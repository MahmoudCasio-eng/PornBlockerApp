# PornBlockerApp
نسخة Android Studio قابلة للبناء لمتصفح آمن.

مهم: هذه النسخة تمنع المواقع داخل المتصفح المدمج فقط. لم يتم الادعاء بأنها VPN على مستوى الجهاز، لأن تنفيذ ذلك يحتاج طبقة شبكات/TUN كاملة واختبارات فعلية.

## الصوت
ضع ملف MP3 للآية 16 باسم:
app/src/main/res/raw/ayah_16.mp3

ثم افتح المشروع في Android Studio واعمل Sync ثم Build APK.
